# ✋ Hand Tracking with OpenCV & MediaPipe

A real-time hand tracking project built using **Python**, **OpenCV**, and **MediaPipe**.  
This application detects and tracks hand landmarks through a webcam feed, enabling gesture-based interaction and computer vision experiments.

---

# 🚀 Features

- ✋ Real-time hand detection
- 🎯 Hand landmark tracking
- 📷 Webcam live video processing
- ⚡ Fast and lightweight performance
- 🧠 MediaPipe hand tracking integration
- 🖐 Multi-hand detection support
- 📌 Finger landmark visualization
- 🔍 Bounding box drawing

---

# 🛠 Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy

# 📸 How It Works

The application performs the following steps:

1. Captures webcam video feed
2. Detects hands in real time
3. Tracks hand landmarks
4. Draws points and connections
5. Displays tracking results on screen

---

# 🧠 Hand Landmark Detection

MediaPipe provides 21 hand landmarks including:

- Thumb
- Index Finger
- Middle Finger
- Ring Finger
- Pinky
- Palm Points
